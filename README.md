# LifeQuest

Минималистичное веб-приложение для личного развития с игровой системой RPG: реальные задачи
превращаются в квесты, приносят опыт, развивают навыки и открывают достижения.

Интерфейс построен на React + TypeScript + Vite. Прогресс сохраняется в LocalStorage браузера,
поэтому квесты, выполненные задания, имя персонажа, настроенная внешность, опыт, монеты и
купленная косметика переживают перезагрузку страницы.

## Запуск

```bash
npm install
npm run dev
```

Сборка и локальный предпросмотр production-версии:

```bash
npm run build
npm run preview
```

Проверка типов выполняется в составе `npm run build`, линтер запускается командой `npm run lint`.

## Опыт и уровни

Шкала уровней находится в [`src/data/levels.ts`](src/data/levels.ts): каждый уровень требует
900 XP, уровень 1 начинается с 0 XP. Текущий прогресс вычисляется из общего опыта, поэтому
полоса опыта и уровень всегда согласованы.

При первом выполнении квеста начисляется его награда XP. У квеста есть флаг `rewarded`,
который сохраняется вместе с прогрессом: повторное выполнение после отмены не приносит опыт
второй раз. Количество выполненных квестов увеличивается только при первом начислении.

## Навыки

Пять навыков соответствуют пяти категориям квестов: «Здоровье», «Интеллект», «Карьера»,
«Финансы» и «Дисциплина». При первом выполнении квест приносит столько же XP навыку своей
категории, сколько и персонажу. Награда берётся из поля `xp` самого квеста, поэтому она зависит
от сложности (25–90 XP в текущих данных).

У навыков отдельная шкала из [`src/data/skillLevels.ts`](src/data/skillLevels.ts): переход
с уровня `L` на `L + 1` требует `200 + 100 × L` XP, то есть 300, 400, 500 XP и так далее.
Уровень персонажа и уровни навыков считаются независимо.

В сохранении хранится только общий (кумулятивный) опыт каждого навыка. Уровень, текущий опыт
и полоса до следующего уровня вычисляются из него, поэтому они не могут рассогласоваться.
Флаг `rewarded` у квеста защищает и опыт персонажа, и опыт навыка от повторного начисления.

## Персонаж и аватар

Внешность собирается из переиспользуемых плоских SVG-элементов и не использует фотографии.
Конструктор открывается в профиле кнопкой «Настроить персонажа» и показывает предпросмотр,
который обновляется сразу при изменении любого параметра. Изменения применяются только после
кнопки «Сохранить внешность»; отмена не трогает сохранение, а «Сбросить» возвращает исходный
образ в предпросмотре.

Доступны:

- 6 оттенков кожи;
- 5 форм волос и 6 цветов волос;
- 6 цветов глаз;
- 3 формы бровей;
- 3 варианта одежды и 6 цветов одежды;
- дополнительные элементы: без дополнений, очки или серьги.

Один и тот же персонаж отображается в верхней панели, боковом меню, карточке на главной, профиле
и в предпросмотре косметики. Фон аватара остаётся отдельной настройкой: его по-прежнему меняют
купленные стили из магазина.

Каталоги параметров находятся в [`src/data/avatarOptions.ts`](src/data/avatarOptions.ts), SVG-рендер —
в [`src/components/Avatar.tsx`](src/components/Avatar.tsx), проверка сохранённых значений — в
[`src/lib/avatar.ts`](src/lib/avatar.ts), а сам конструктор — в
[`src/components/AvatarBuilder.tsx`](src/components/AvatarBuilder.tsx). У каждого варианта есть
стабильный `id` и зарезервированное поле `unlockId`: будущие причёски, одежду и аксессуары можно
будет открывать за монеты, не меняя структуру состояния.

## Монеты и магазин

Стартовый баланс — 1240 монет. За первое выполнение квеста начисляются монеты по сложности:
лёгкий — 10, средний — 20, сложный — 35. Эпического уровня сложности в модели квестов пока нет,
поэтому отдельная награда для него не добавлена. Флаг `rewarded` защищает и монеты: отмена,
повторное выполнение и повторное нажатие не приносят их снова.

В состоянии игры хранятся текущий баланс, всего заработанные и всего потраченные монеты, а также
список купленных предметов. Баланс не может стать отрицательным: покупка сначала проверяет
стоимость, владение и достаточность средств, и только потом меняет состояние.

Магазин использует существующие четыре стиля аватара из [`src/data/demoData.ts`](src/data/demoData.ts).
«Лавандовая аура» и «Мятный рассвет» доступны изначально, «Тёплый закат» стоит 900 монет, а
«Глубокий океан» — 1200. У предмета есть одно из состояний: доступен, куплен или надет.
Покупка и надевание разделены: после покупки предмет нужно надеть отдельно. Надевание и замена
стиля не списывают монеты. В профиле показываются только купленные стили; новый стиль появляется
там после покупки.

Покупки, надевание и расчёт наград находятся в [`src/lib/shop.ts`](src/lib/shop.ts). Реальных
платежей, рекламы и покупок за настоящие деньги нет.

## Достижения

Каталог достижений находится в [`src/data/achievements.ts`](src/data/achievements.ts), а расчёт
состояния и прогресса — в [`src/lib/achievements.ts`](src/lib/achievements.ts). Компоненты получают
уже готовые данные и не содержат игровых правил.

Названия, иконки и темы восьми исходных карточек сохранены. Условия, которые зависели от
календаря или времени и не хранились в состоянии игры, переведены на реальные счётчики квестов;
к ним добавлены три записи, закрывающие недостающие условия из требований: 50 выполненных
квестов, 10 уровень любого навыка и 10 000 заработанных XP. Условия распределены так:

- «Первый шаг», «На волне», «Пятьдесят шагов» и «Марафонец» — 1, 10, 50 и 100 квестов;
- «Ранний старт», «Мастер фокуса», «Дисциплина месяца» и «Финансовый фундамент» — 5, 10, 30 и
  50 квестов соответствующей категории;
- «Легенда LifeQuest» — 20 уровень персонажа;
- «Мастер навыка» — 10 уровень любого из пяти навыков;
- «Копилка опыта» — 10 000 XP.

Прогресс считается из текущего состояния игры: общего опыта, количества выполненных квестов,
опыта навыков и счётчиков по категориям. В карточке видны условие и состояние, у незакрытого
достижения — текущее значение и цель, у полученного — дата. Повторное выполнение уже
вознаграждённого квеста не увеличивает ни опыт, ни счётчики, поэтому не меняет и прогресс
достижений.

Проверка новых достижений выполняется после начисления награды за квест — то есть после любого
изменения уровня персонажа или навыка. При загрузке сохранения условия проверяются повторно,
чтобы старые сохранения получили уже заслуженные достижения. Дата фиксируется один раз; при
следующих проверках полученное достижение повторно не выдаётся.

## Сохранение

Состояние игры хранится под ключом `lifequest.game.v1`:

- имя персонажа и выбранный стиль аватара;
- список квестов (включая созданные пользователем) и их выполнение;
- общий опыт и количество выполненных квестов;
- флаг начисления опыта для каждого квеста;
- кумулятивный опыт каждого из пяти навыков;
- количество вознаграждённых квестов по каждой категории;
- даты получения достижений (идентификатор → дата в формате `ГГГГ-ММ-ДД`);
- баланс, всего заработанные и всего потраченные монеты;
- список купленных косметических предметов;
- настройки внешности: кожа, причёска и её цвет, глаза, брови, одежда, её цвет и аксессуар.

При первом запуске создаются начальные данные, при последующих загружается сохранение.
Повреждённая запись, неизвестная версия или недоступный LocalStorage не мешают запуску:
приложение безопасно откатывается к начальным данным.

Сохранения версий 1–4 поддерживаются. У версии 1 нет опыта навыков: имя, аватар, квесты,
выполненные задания и опыт персонажа сохраняются, а навыки получают начальный демонстрационный
прогресс. У версии 2 есть навыки, но нет счётчиков категорий и достижений: счётчики
восстанавливаются из baseline и отметок `rewarded` у квестов, а достижения выдаются по уже
достигнутым условиям. Версия 3 содержит достижения, но ещё не содержит монет и покупок. Версия 4
содержит валюту и магазин, но ещё не содержит конструктора внешности.

При миграции старых сохранений монеты не начисляются заново за уже выполненные квесты. Баланс
получает стартовое значение, купленными считаются два базовых стиля, а выбранный ранее стиль
сохраняется и становится доступным, даже если в старой версии его можно было выбрать без
покупки. Если данных о внешности нет, используется исходный образ; выбор фона (темы) при этом
сохраняется. Имя, фон, квесты, опыт персонажа, навыки, достижения, монеты и покупки не теряются.
После загрузки сохранение автоматически записывается в версии 5.

## Структура

```
src/
  components/          общие компоненты (аватар, полоса опыта, карточки, графики, модальное окно)
    navigation/        боковая панель, верхняя строка и мобильная нижняя навигация
  data/                демо-данные, категории, уровни, достижения, косметика и каталоги внешности
  hooks/               маленький hash-роутер
  lib/                 сохранение, достижения, логика магазина и проверка внешности
  screens/             пять экранов приложения
  styles/              токены дизайна, базовые стили, компоненты, экраны
  types.ts             общие типы
  App.tsx              состояние игры, начисление опыта и маршрутизация
```

Разделы открываются по hash-адресам (`#/home`, `#/quests`, `#/skills`, `#/rewards`, `#/profile`),
поэтому прямые ссылки работают на GitHub Pages без серверных перенаправлений.

## Публикация на GitHub Pages

1. Запушьте проект в репозиторий GitHub (ветка `main`).
2. В **Settings → Pages** выберите источник **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт при каждом пуше в `main`.

В `vite.config.ts` используется `base: './'`, поэтому сборка подходит и для project pages
(`https://<user>.github.io/<repo>/`), и для локального запуска.

## Что остаётся демонстрационным

Календарь активности, серия дней и дерево навыков пока используют фиксированные данные. Бонус
ежедневного испытания (+120 XP) отображается, но автоматически не начисляется. Недельный график
начинается с демо-снимка; заработанный опыт добавляется к текущему дню. Магазин работает только
на игровых монетах: реальных платежей, рекламы и ежедневных денежных наград нет.
